# AI-Driven-Discovery-of-Underutilized-Anti-Cancer-Crops-in-Indigenous-Food-Systems
AI based image recognization:

This project focuses on leveraging Artificial Intelligence and image recognition techniques to identify underutilized indigenous crops with potential anti-cancer properties. The goal is to bridge the gap between traditional knowledge and modern AI-driven analysis to support research in healthcare and sustainable agriculture.

Using Python and machine learning, the system analyzes crop images and associated phytochemical data to detect and classify plant species. It then evaluates their bioactive compounds to highlight crops that may have cancer-preventive potential.

The project workflow includes data collection, preprocessing, image-based classification, feature extraction, and model evaluation. A Google Colab environment is used for experimentation, enabling easy training and testing of models.

This work demonstrates how AI can assist in early-stage scientific discovery by combining computer vision with domain knowledge from agriculture and health sciences.
